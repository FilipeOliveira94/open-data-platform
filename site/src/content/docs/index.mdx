A reproducible open-source data platform for local development on Windows 11 + WSL2 + Docker Compose, with an AWS deployment path expressed later as Terraform Infrastructure as Code.

## Current status

| Status | Scope |
| --- | --- |
| **Verified** | Phase 0 — repository, Python 3.12 toolchain, PostgreSQL 16, MinIO, lint/tests, CI |
| **Planned** | Phases 1–7 — ingestion, lakehouse, orchestration, CDC, observability, CI expansion, AWS IaC |
| **Planned** | Phase 8 — report polish and public hosting |

