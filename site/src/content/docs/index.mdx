A reproducible open-source data platform for local development on Windows 11 + WSL2 + Docker Compose, with an AWS deployment path expressed later as Terraform Infrastructure as Code.

## Current status

| Status | Scope |
| --- | --- |
| **Verified** | Phase 0 — repository, Python 3.12 toolchain, PostgreSQL 16, MinIO, lint/tests, CI |
| **Verified** | Phase 1 — raw ingestion from Olist, DummyJSON, PostgreSQL, the demo storefront clickstream, and IBGE |
| **In progress** | Phase 2 — lakehouse and analytics (see the repository status ledger) |
| **Not started** | Phases 3–7 — orchestration, CDC, observability, CI expansion, AWS IaC |
| **Not started** | Phase 8 — JupyterLab exploration and Superset charts over Gold |
| **Not started** | Phase 9 — report polish and public hosting |
