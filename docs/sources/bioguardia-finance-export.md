# BioGuardia Finance daily export

| Field | Value |
| --- | --- |
| Name | BioGuardia Finance daily export |
| Type | Generated daily file drop (gzip CSV) with a manifest |
| Role | Payments of the environmental fines the Operations Hub issues, from the agency's finance system |
| URL | None. The generator is local (`open_data_platform.simulators.bioguardia`) |
| Gold Domain | Planned in Phase 11: reconciliation of fines and payments (P11-12) |
| License | Generated by this repository |
| Access | MinIO bucket `odp-landing`, prefix `bioguardia_finance/`; same service and commands as the [ops export](bioguardia-ops-export.md) |
| Decision | [ADR-0027](../decisions/0027-bioguardia-synthetic-sources.md) |
| Related Issue | P11-02 (generator); P11-05 (ingestion, not built) |

The finance drop has the same layout, manifest, and `_SUCCESS` rules as the [ops export](bioguardia-ops-export.md), under `bioguardia_finance/export_date=D/export_version=1/`. It is released at D+1 06:00 BRT and holds the payments the finance system posted on D. A payment is posted 0 to 3 days after it is paid, so a payment can arrive after the notice it settles changed status in the ops drop (in transit). There is no version 2 for this source.

Payments are matched to `infraction_notices` of the ops export by `notice_id`. Cases planted by the generator: full payment, installments, partial payment, overpayment, duplicate payment, an unmatched reference (one wrong digit in `notice_id`, about 3%), and a payment followed by a refund after a cancellation. Amounts are exact BRL decimals.

## Tables

### `fine_payments`

Payments of infraction notices from the finance system, in BRL. Cases: full, installments, partial, overpaid, duplicate, unmatched reference, paid then cancelled (refund). Change type: append. Key: `payment_id`. File: `fine_payments.csv.gz`.

Grain: One payment or refund the finance system posted on the export date. A payment is posted 0 to 3 days after it is paid.

| Column | Type | Nullable | Classification | Description |
| --- | --- | --- | --- | --- |
| `payment_id` | string | no | internal | Payment identifier. |
| `notice_id` | string | no | internal | Notice the payer referenced; about 3% carry a wrong digit and match no notice. |
| `payer_document` | string | no | pii | CPF or CNPJ of the payer, wrong check digit by construction. |
| `paid_on` | date | no | internal | Date the payer paid (business date). |
| `posted_on` | date | no | internal | Date finance posted it; decides the drop. |
| `amount_brl` | decimal(14,2) | no | internal | Amount in BRL; a refund is positive with is_refund true. |
| `payment_method` | string | no | internal | Closed set: boleto, pix, darf, transfer. |
| `bank_reference` | string | no | internal | Bank transaction reference. |
| `is_refund` | boolean | no | internal | True when the agency returned the money. |
