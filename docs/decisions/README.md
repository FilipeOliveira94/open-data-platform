# Architecture Decision Records (ADRs)

Detailed records for choices indexed in [`DECISIONS.md`](../../DECISIONS.md).

| | |
| --- | --- |
| Index | [`DECISIONS.md`](../../DECISIONS.md) — proposed vs implemented stack, status |
| Template | [`_template.md`](_template.md) |
| Naming | `NNNN-short-slug.md` (zero-padded), matching index IDs D-001 ↔ ADR-0001 |

Each ADR covers context, decision, alternatives, consequences, evidence and revisit triggers. Do not duplicate full ADR text in `DECISIONS.md`. Update both the ADR and the index row when status or the implemented stack changes.
